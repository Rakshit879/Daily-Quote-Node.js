# Random-Quote-Generator-using-Node.js

📝 Random Quote Generator using Node.js

I have developed a web app that generates random quotes with a twist—this is not just a typical API call. In this project, I built a custom Node.js server that acts as the middle layer between the frontend and the quote data. This project demonstrates my Node.js skills by not only fetching and serving the data but also writing it to a local JSON file.

Every time a new quote is generated by clicking the "Generate" button, the quote and its author are saved into a JSON file on your computer. This showcases my ability to perform file operations using Node.js, making the app more dynamic and functional.

💻 Tech Stack:
HTML
CSS
JavaScript
Node.js

🚀 How to Run the App:
1. Clone or download the code into your code editor.
2. Open the terminal and navigate to the project folder (where index.js is located).
3. Start the server by running the command:

"node index.js"

4. Open your browser and go to:

"http://localhost:3000/"

Your application will be up and running there.

📂 Features:
1. Random quote generation via a button click
2. Backend built using a custom Node.js server
3. Every generated quote and its author is saved in a local JSON file
4. Demonstrates use of Node.js for API handling and file system interaction
